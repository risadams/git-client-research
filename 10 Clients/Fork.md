## Installation
Download from git-fork.com. Windows: `winget install Fork.Fork`. macOS: `brew install --cask fork`.

## Features
- Fetch, pull, push, commit and amend, branch and tag management
- Line-level staging, side-by-side diff, image diffs
- Interactive rebase, merge-conflict helper and resolver
- Blame, file and directory history, tree browser at any commit
- Reflog recovery, submodules, git-flow, LFS
- GitHub notifications
