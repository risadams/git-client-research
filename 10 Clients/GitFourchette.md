## Installation
Flathub (`flatpak install flathub org.gitfourchette.gitfourchette`), AppImage from GitHub releases, or run from source with system Qt.

## Features
- Python and Qt UI aimed at KDE Plasma
- Hunk and line staging, commits, branch management
- Merge conflict help with ours/theirs previews
- Git LFS awareness
- Recent versions use the git CLI instead of libgit2, improving SSH and hook compatibility
