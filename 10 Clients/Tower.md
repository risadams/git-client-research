## Installation
Download from git-tower.com. One license covers both macOS and Windows.

## Features
- Undo Anything (undo most operations incl. commits, merges, branch deletes)
- Drag and drop everywhere (merge, rebase, cherry-pick)
- Pull requests and Services Manager for GitHub, GitLab, Bitbucket, Azure DevOps
- Pro: Stacked Branches, Custom Workflows, Graphite support, Branch Cleanup, Self-Hosted repositories, Merge Detection
- Interactive rebase UI, conflict solver, submodules, LFS
- Enterprise: SAML SSO, advanced deployment
