## Installation
Download from sublimemerge.com. Windows: `winget install SublimeHQ.SublimeMerge`. macOS: `brew install --cask sublime-merge`. Linux: apt/yum repos.

## Features
- Very fast; custom Git reading library
- Syntax-highlighted diffs, 3-way merge
- Command palette
- Line-level staging, commit editing, blame, interactive rebase
- Themes; pairs with Sublime Text
