## Installation
Windows installer, portable binary, or Microsoft Store. macOS and Linux via Homebrew. Linux also AUR, GURU (Gentoo), apt. Prebuilt binaries on GitHub Releases. Requires Git 2.50 or newer.

## Features
- Pull/push, staging, commits, worktrees, branching, full history
- Multi-repository browsing
- Inline and side-by-side diffs, 2-way and 3-way merge tools
- Commit signature verification badges, themes
- Usable as `git difftool` and `mergetool`
- Planned Pro tier: Claude Code, Codex, and GitHub CLI integrations; GitHub and Azure DevOps integrations; coverage workflows
