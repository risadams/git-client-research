## Installation
`brew install lazygit`, `winget install JesseDuffield.lazygit`, `scoop install lazygit`, distro packages, `go install`.

## Features
- Panel-based terminal UI
- Stage by line, interactive rebase, cherry-pick, bisect
- Worktrees, submodules, custom commands
- Works over SSH
