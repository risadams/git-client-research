Installer from GitHub releases (gitextensions/gitextensions). `winget install GitExtensionsTeam.GitExtensions`.

## Features
- Standalone UI plus Visual Studio extension and shell extension
- Commit graph, stash, rebase, submodules
- Plugin system, built-in diff and merge tooling
