## Installation
Download from smartgit.dev. Windows: `winget install Syntevo.SmartGit`. Linux: tar.gz, deb, rpm, snap.

## Features
- Graph and log with powerful filters
- Integrated 3-way merge and conflict solver
- Pull requests and reviews for GitHub, GitLab, Bitbucket, Azure DevOps
- Hobby tier lacks self-hosted provider integrations
- Git-flow, submodules, LFS, SVN bridge, Mercurial history
- Built-in file compare, bundles, hooks

## Ease of use
Dense and power-oriented; steeper than GitHub Desktop, gentler than raw Git.

Dense, power-oriented UI. Free for non-commercial use suits solo hobby and open-source work. Commercial licensing, license server, and self-hosted provider integrations suit teams.

## Best for
Linux users who want a full-featured GUI, open-source maintainers (free), mixed-VCS shops.

## Caveats
UI is utilitarian. Platform support and trial terms were not stated on the pricing page I fetched.
