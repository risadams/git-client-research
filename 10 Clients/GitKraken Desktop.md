## Installation
Download from gitkraken.com. Windows: `winget install Axosoft.GitKraken`. macOS: `brew install --cask gitkraken`. Linux: deb, rpm, snap.

## Features
- Interactive commit graph
- Merge conflict editor
- Integrations: GitHub, GitLab, Bitbucket, Azure DevOps; Jira Cloud and Trello on paid tiers
- AI: commit messages, merge conflict resolution, Commit Composer, PR descriptions, stash messages, commit and branch explanations, code review (bring-your-own-key allowed)
- Launchpad and Workspaces for multi-repo work
- Built-in terminal, GitFlow support, LFS

Visually friendly; graph-first. Free tier restrictions on private repos are the main friction.

Graph-first view helps learning. The free tier excludes private repos, which hurts solo work. Business and Enterprise tiers add org-level AI controls and team features.

## Best for
Visual thinkers, cross-platform teams, people who want AI assist built in.

## Caveats
Free tier limited to local and public remotes. Electron-based, heavier on memory. Pricing tiers change often; check live page.
