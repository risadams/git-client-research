## Installation
Windows: `winget install polrivero.GitHubDesktopPlus`. macOS: `brew install pol-rivero/tap/github-desktop-plus`. Linux: apt/rpm repos, Flatpak (Flathub), AUR (`desktop-plus`), AppImage. Note the project and AUR packages were renamed from 'GitHub Desktop Plus' to 'Desktop Plus' around June 2026.

## Features
- Up-to-date fork of GitHub Desktop with Linux builds
- Multi-account support
- Bitbucket and GitLab integration
- Permanent-discard option for many changed files
- CLI for opening and cloning repos
