## Installation
Linux AppImage, `sudo port install gitqlient` on macOS, distro packages (Fedora, FreeBSD, Gentoo). Also a Qt Creator plugin.

## Features
- Qt/C++ client forked from QGit
- Visual history, hunk staging, rebase
- Gerrit and forge integration
