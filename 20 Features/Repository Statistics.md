# Repository Statistics and Visualizations

**Group:** History and investigation  
**Clients with this feature in my notes:** 2 of 66

## What it does
Charts and summaries such as contributor heatmaps, repository size, branch/tag counts, code statistics.

## Why it matters
Helpful for onboarding, audits, and understanding hotspots.

## Git equivalent
`git shortlog -sn`, third-party tools

## What to check when evaluating
Are these live or computed on demand? Do they scale to large repos?
