# Patches

**Group:** Staging and commits  
**Clients with this feature in my notes:** 2 of 66

## What it does
Create, apply, or view patch files from within the app.

## Why it matters
Useful for mailing-list workflows and sharing changes without a remote.

## Git equivalent
`git format-patch`, `git apply`, `git am`

## What to check when evaluating
Can you export from selected commits and apply a patch file via the UI?
