# Folder and Directory Compare

**Group:** Diff, compare and merge  
**Clients with this feature in my notes:** 2 of 66

## What it does
Compare two folders, including folders that are not Git repositories.

## Why it matters
Useful for config audits and comparing build outputs.

## Git equivalent
`git diff --no-index`, `diff -r`

## What to check when evaluating
Can it ignore patterns and then merge selected files?
