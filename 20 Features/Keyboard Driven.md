# Keyboard-Driven Workflow

**Group:** Interface and ergonomics  
**Clients with this feature in my notes:** 11 of 66

## What it does
Operate the app with shortcuts, a command palette, or Magit-style mnemonics instead of the mouse.

## Why it matters
Faster for power users and accessible for non-mouse use.

## Git equivalent
The CLI itself

## What to check when evaluating
Are shortcuts discoverable and remappable? Is there a command palette?
