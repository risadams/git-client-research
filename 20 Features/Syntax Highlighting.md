# Syntax Highlighting in Diffs

**Group:** Diff, compare and merge  
**Clients with this feature in my notes:** 2 of 66

## What it does
Colors code in diffs by language.

## Why it matters
Makes diffs far easier to read than raw red and green.

## Git equivalent
No built-in equivalent; some pagers add it

## What to check when evaluating
How many languages? Does it apply to merge views too?
