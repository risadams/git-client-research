# Rich File Preview

**Group:** Diff, compare and merge  
**Clients with this feature in my notes:** 2 of 66

## What it does
Renders Markdown, PDF, CSV, JSON, Mermaid, or similar next to the raw diff.

## Why it matters
Reviewing documentation and data files visually.

## Git equivalent
None; typically only raw text diffs

## What to check when evaluating
Which formats are rendered, and is preview available for historic versions?
