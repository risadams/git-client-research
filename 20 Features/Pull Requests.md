# Pull and Merge Request Integration

**Group:** Hosting and workflow integrations  
**Clients with this feature in my notes:** 8 of 66

## What it does
Create, review, comment on, and merge pull or merge requests without leaving the app.

## Why it matters
Cuts context switches between client and browser.

## Git equivalent
`gh pr create`, `glab mr create` and the web UI

## What to check when evaluating
Which hosts are supported (GitHub, GitLab, Bitbucket, Azure DevOps)? Are inline review comments supported?
