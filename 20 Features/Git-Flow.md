# Git-Flow Support

**Group:** Branching models and history rewriting  
**Clients with this feature in my notes:** 4 of 66

## What it does
Built-in helpers for the git-flow branching model (feature, release, hotfix branches).

## Why it matters
Teams that follow git-flow get one-click branch starts and finishes.

## Git equivalent
`git flow feature start`, `git flow release finish`

## What to check when evaluating
Is it the git-flow AVH CLI under the hood or a custom implementation? Can you configure naming?
