# Editor and IDE Integration

**Group:** Interface and ergonomics  
**Clients with this feature in my notes:** 9 of 66

## What it does
Git features embedded in an editor or IDE rather than a standalone window.

## Why it matters
Keeps you in one tool for coding and committing.

## Git equivalent
None

## What to check when evaluating
Is it only a status panel, or does it support full history and merge flows?
