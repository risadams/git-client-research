# Stash

**Group:** Staging and commits  
**Clients with this feature in my notes:** 11 of 66

## What it does
Park uncommitted changes on a shelf so you can switch context, then restore them later.

## Why it matters
Safe context switching when you are not ready to commit.

## Git equivalent
`git stash`, `git stash pop`

## What to check when evaluating
Can you stash only selected files? Are stashes named and browsable? Can you apply without dropping?
