# Commit Amend

**Group:** Staging and commits  
**Clients with this feature in my notes:** 4 of 66

## What it does
Fold new changes or a new message into the most recent commit from a button or menu.

## Why it matters
Fast fix-ups of the last commit without touching the command line.

## Git equivalent
`git commit --amend`

## What to check when evaluating
Does it warn you when the commit was already pushed? Can you amend only the message?
