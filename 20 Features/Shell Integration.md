# Shell and File Manager Integration

**Group:** Interface and ergonomics  
**Clients with this feature in my notes:** 3 of 66

## What it does
Adds Git actions and status icons to the operating system file manager (Explorer, Finder).

## Why it matters
Version control without opening a separate app.

## Git equivalent
None

## What to check when evaluating
Do overlay icons slow down large folders? Are all actions in the context menu?
