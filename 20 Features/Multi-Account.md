# Multiple Accounts

**Group:** Hosting and workflow integrations  
**Clients with this feature in my notes:** 1 of 66

## What it does
Sign in with more than one account for the same host (for example personal and work GitHub).

## Why it matters
Avoids credential juggling.

## Git equivalent
Per-repo credential config or SSH host aliases

## What to check when evaluating
Is account selection per repo automatic?
