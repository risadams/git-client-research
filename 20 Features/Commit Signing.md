# Commit Signature Verification

**Group:** Privacy, security and enterprise  
**Clients with this feature in my notes:** 2 of 66

## What it does
Shows whether commits are GPG, SSH, or S/MIME signed and verified.

## Why it matters
Supply-chain and compliance visibility.

## Git equivalent
`git log --show-signature`, `git commit -S`

## What to check when evaluating
Can it also sign commits, and which key types?
