# Data Reliability

Extends [[Confidence Levels]] to market data.

| Grade | Meaning |
|---|---|
| V | Vendor or company primary page or announcement |
| P | Primary platform page (for example a GitHub repository page) |
| S | Secondary: news, directories, review sites |
| C | Vendor marketing claim, unverified |
| B | Background knowledge, not rechecked |
| T | Tested hands-on by Claude in a sandbox; see [[Benchmarks]] |

## Rules used

1. No number appears without a source named in the page.
2. Where sources conflict, both values are listed and one is chosen with a reason.
3. Vendor claims are labeled as claims.
4. Nothing here was tested hands-on.
