# Market Research Hub

Scope: the commercial and open-source landscape around Git clients. Snapshot date 2026-11-09. Product comparison lives in [[01 Comparison Table]]; this section covers the market around those products.

> [!warning] What the data can and cannot say
> No public source measures market share for Git GUI clients. The Stack Overflow survey, JetBrains survey and similar studies ask about hosting platforms and IDEs, not Git GUIs. Everything below is either a vendor claim, a GitHub star count, a category-level review-site metric, or a funding record. Read [[Data Reliability]] before quoting any number.

## Headline findings

1. **Free is the default price anchor.** GitHub Desktop, Sourcetree, GitKraken Community, GitButler (individuals), SmartGit (non-commercial), and every terminal UI cost nothing. Paid vendors sell on speed, polish, safety nets (undo), and team features.
2. **Three ownership models.** Corporate funnel (Microsoft, Atlassian), private-equity roll-up (GitKraken), and small independents (fournova, syntevo, Sublime HQ, Fork). VC money entered in 2026 with GitButler.
3. **Open-source terminal UIs lead on visible popularity.** LazyGit has 81.6k GitHub stars, about 3.7 times GitHub Desktop (21.9k). Stars measure developer interest, not paying users.
4. **Review-site mindshare for Sourcetree is slipping.** PeerSpot shows 6.3% in the Version Control category in November 2026, down from 6.9% a year earlier. That category includes hosting products, so it does not measure Git GUIs alone.
5. **AI agents are the new wedge.** GitButler's $17M Series A is explicitly about parallel work by coding agents.
